# 🚀 CareerForge AI

## AI-Powered Resume Analyzer & Career Intelligence Platform

CareerForge AI is an intelligent career guidance application that analyzes a user's resume and compares it with their target job role.

The application uses AI to identify skills, analyze job requirements, calculate a career match score, detect skill gaps, simulate the impact of learning new skills, and provide personalized career guidance.

## ✨ Features

- 📄 PDF Resume Upload and Text Extraction
- 🎯 Dynamic AI Job Requirement Analysis
- 🤖 AI-Powered Resume Analysis
- 📊 Career Match Score
- 🔍 Skill Gap Analysis
- ✅ Matching Skills Identification
- ❌ Missing Skills Identification
- 📈 Detailed Score Breakdown
- 🔮 What-If Skill Simulator
- 💬 AI Career Assistant
- 🗺️ Personalized Learning Roadmap
- ✨ Resume Improvement Suggestions
- 🎨 Interactive Streamlit User Interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Groq AI
- PyPDF
- JSON
- AI and Machine Learning Concepts
